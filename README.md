# RedDotsFinder — moved

Development has moved to
[LodopWithGolang-Demo/tools/red-dots](https://github.com/Herts/LodopWithGolang-Demo/tree/master/tools/red-dots),
where the coordinate generator and printing demo now share one workflow.

The maintained version includes a command-line interface, configurable paper
dimensions and calibration offsets, connected-marker detection, JSON output,
input validation, setup instructions, and automated tests. See the
[printing workflow](https://github.com/Herts/LodopWithGolang-Demo#readme) for setup.

This repository preserves the original source and document fixtures. It is kept
as a historical archive; use the consolidated repository for new work.
